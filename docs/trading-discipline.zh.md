## 核心原则

| 维度                    | 建议     |
| ----------------------- | -------- |
| 看盘顺序                | 结构优先 |
| 单笔风险基准（上沿 2%） | 1%       |
| 入场门槛                | 多源确认 |
| 默认状态                | 空仓合法 |

> 指标是同一价格的不同投影，堆再多同类指标不会提高胜率。有效组合 = 趋势/结构 + 动量 + 波动或成交量，且彼此回答不同问题。合约上更常踩的坑是把杠杆倍数或保证金占用当成「风险」——真正的风险是止损打掉时账户亏多少。做法是固定风险 %，用 ATR 或失效位反推张数，再另设当日最大亏损（4R–6R）当真正的保险丝。风险 % 定多少不是「仓位够不够大」的问题——1% 风险配 2% 止损就是半个权益的名义仓位，做得起来——而是拿回撤深度换单笔收益绝对值的问题。

## 看盘流程

### 1. 先定结构

日线 / 4H 看趋势、摆动高低与关键位；15m–5m 只负责入场时机。大周期无方向时，小周期全是噪音。

### 2. 指标做确认

用均线/MACD 对齐趋势，用 RSI/KD 看是否过热或背离，用布林/ATR 估波动与止损宽度——不要用指标「预测」方向。

### 3. 量能与盘口

成交量、VWAP、持仓量（合约）回答「有没有人跟」。无量突破、价涨持仓降，优先当假动作。

### 4. 等多源确认再动手

至少两类独立证据同向：例如结构突破 + 放量，或回踩均线 + RSI 离开超卖且 MACD 柱转正。单指标亮灯不够。

## K 线与结构技巧

| 主题             | 要点                                                                                                                                                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 多周期对齐       | 只在大周期方向上找顺势单；逆势最多做反弹/回踩短线，仓位减半。                                                                                                                                                                 |
| 关键位优先       | 前高前低、整数关口、日/周开盘、成交密集区。合约上要多想一层：这些位置同时是止损堆积的地方，所以「先被扫穿再反向走」是常态而不是意外。把它当预期——用扫穿后收回来做入场，比把止损贴在位置正后面强。没有明确失效位，就不该开仓。 |
| 假突破识别       | 突破瞬间量能不足、长影线拒绝、收盘未能站稳——优先当假突破。                                                                                                                                                                    |
| 波动扩张 vs 压缩 | 窄幅盘整后的第一根放量 K 更有信息量；剧烈波动后追单胜率差。                                                                                                                                                                   |
| 影线与收盘       | 看收盘相对实体，不看盘中极值。但合约上要分清两种长影：有量、落在关键位上、之后没有跟随的，是拒绝；发生在强平潮里、穿过一堆止损又立刻收回的，是清算插针——它不含方向信息，只说明那里挂了多少单。                                |
| 相对强弱         | 同板块选领先/落后：大盘弱时仍强的品种更值得做多，反之亦然。                                                                                                                                                                   |

## 常用技术指标：各自回答什么

先按「角色」选指标，再谈参数。同类指标（如 RSI 与 Stochastic）同时用几乎等于重复计数。这张表里全是价格的再加工——合约独有的那层数据（费率、持仓量、基差、强平）不在这里，它在下一节。

| 角色       | 常见工具                                   | 怎么用 / 别怎么用                                                                                                                           |
| ---------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 趋势与位置 | MA / EMA（20·50·200）、Ichimoku、VWAP、ADX | 价格在均线上方且均线多头排列 → 偏多；回踩不破再做。别用均线金叉当唯一入场。ADX 只说趋势强不强、从不说方向：20 以下当没有趋势，25 以上当有。 |
| 动量       | MACD、RSI、ROC、Stochastic                 | 看方向与背离：价格新高而 RSI/MACD 不过新高 → 动能衰竭。别在趋势中段死磕超买超卖。                                                           |
| 波动与通道 | 布林带、Keltner、ATR、Donchian             | 带宽收窄后突破常跟趋势段；ATR 定止损宽度。别在带宽已极大时追穿轨。                                                                          |
| 成交量     | 成交量、OBV、VWAP、成交量分布              | 突破需放量确认；缩量回踩健康。价量背离要提高警惕。                                                                                          |
| 结构辅助   | 斐波那契回撤/扩展、Pivot、水平供需         | 回撤位与前高前低重合时权重更高。斐波那契单独不成系统。                                                                                      |

## 合约数据：图表看不见的那一半

上面那张表里的每一条，本质都是价格的再加工——换个市场照样能算。资金费率、持仓量、基差、多空比、强平量不是：它们描述的是仓位——谁手上拿着什么、付着多少成本、有多脆。这是一根 K 线在结构上装不下的信息，也是散户在合约上最接近 edge 的东西，因为它不是价格的滞后变换。所以它单独占一节，而不是塞进指标表里当第七行。

| 读数                  | 它在说什么                               | 怎么用                                                            |
| --------------------- | ---------------------------------------- | ----------------------------------------------------------------- |
| 资金费率              | 多空哪一边在付钱，付多少                 | 先当成本算进 R。持续极端 = 一侧拥挤，提高反向警觉，但它不能择时   |
| 持仓量                | 场上未平仓合约的总量：钱在进场还是在离场 | 永远和价格配对读，见下面的四象限。单独看持仓量没有意义            |
| 基差                  | 合约相对现货指数的偏离                   | 正基差极端 = 合约端在追现货。回归是必然的，时间不是——别拿它当入场 |
| 多空比 / 大户散户分歧 | 账户层面的拥挤度，以及谁站在哪一边       | 看它自己的偏离，不看绝对水平。分歧拉大常出现在拐点附近            |
| 强平量                | 谁在被动出局                             | 风险开关，以及挤仓配方的触发。绝不当趋势确认                      |
| 主动成交方向          | 谁在越过价差促成成交                     | 方向证据里比较硬的一条。极端读数多出现在一段行情的末端            |
| 盘口价差              | 此刻进出各要付多少                       | 成本，不是信号。变宽的时候不该是你开新仓的时候                    |

### 价格 × 持仓量：四个象限

| 组合          | 在发生什么         | 含义                                                         |
| ------------- | ------------------ | ------------------------------------------------------------ |
| 价涨 + 持仓增 | 新的多头资金进场   | 最像真趋势的一种组合。顺势可以持，止损按结构走               |
| 价涨 + 持仓降 | 空头在平仓         | 空头回补推动的，燃料是有限的。别当趋势起点，冲高优先减仓     |
| 价跌 + 持仓增 | 新的空头进场       | 下跌有人接力。反弹优先当反抽处理，不急着抄                   |
| 价跌 + 持仓降 | 多头在平仓或被清掉 | 去杠杆。往往落在阶段性底部区域附近，但要等强平停下来再谈入场 |

| 组合起来看                       | 大概率是什么局               | 怎么做                                       |
| -------------------------------- | ---------------------------- | -------------------------------------------- |
| 费率极端 + 持仓量高位 + 价格滞涨 | 拥挤已经到了尽头，挤仓在酝酿 | 停止加仓，缩短持仓；把挤仓反转那个配方准备好 |
| 费率温和 + 持仓量随价格同步增    | 健康的趋势，钱在正常进场     | 顺势做，正常持仓时长，不必因为费率提前跑     |
| 强平量骤增 + 持仓量骤降          | 清算正在进行中               | 不追方向。等它停、等价格收回被扫的位         |
| 基差与费率背向                   | 现货和合约在打架，一致性不足 | 降低对这一笔的确定性预期，仓位减半或干脆跳过 |

### 这层数据的边界

- 它说的是仓位，不是预测。拥挤能持续数周，费率极端本身从来不是入场理由。
- 它改变的是你的门槛和仓位大小，不是你的方向——方向仍然由结构给。
- 所有读数都要看相对自己历史的偏离，不看绝对值：不同合约的费率、基差、多空比的常态差得很远。

## 指标组合：可直接套用的配方

### 顺势回踩（趋势市）

- **条件**：价格在 EMA20/50 之上（或之下做空），大周期 MACD 柱同向。
- **入场**：回踩 EMA20 或布林中轨，RSI 落到中轴附近（约 40–50）后重新上行，且未破前低。
- **过滤**：成交量回踩萎缩、再启动放量；ATR 正常未极端放大。
- **目标**：前高，或上一波段的等幅扩展；先算够不够 1.5R，不够就不做。
- **失效**：收盘跌破回踩均线或前摆动低点。

### 突破接力（压缩后）

- **条件**：布林带宽或 ATR 处于近期低位（波动压缩）。
- **入场**：收盘突破箱体/Donchian/前高，且成交量明显放大。
- **确认**：MACD 柱翻向突破方向，或价格站稳 VWAP/突破均线一侧。
- **目标**：箱体高度等幅投影；达不到 1.5R 就放掉这一笔。
- **失效**：长影刺破后收回箱内，或突破后量能迅速枯竭。

### 背离反转（震荡/末端）

- **条件**：大周期已横盘或趋势斜率变缓，非单边强趋势中段。
- **信号**：价格创新高/低，RSI 或 MACD 未跟创新高/低（背离）。
- **入场**：等结构确认——破短期趋势线或收复关键 K 线，而不是背离一出现就开仓。
- **目标**：前一个结构低/高点或区间中轨。反转单不追远目标。
- **注意**：强趋势里背离可连续多次，仓位要小、止损要紧。

### 挤仓反转（合约专属）

- **条件**：资金费率单边极端且持续，持仓量在高位——一侧已经拥挤到要付钱才留得住。
- **触发**：一波强平潮把价格打穿关键位，持仓量同时骤降：那是仓位在被清掉，不是新钱在进场。
- **入场**：等强平停下来、价格收回被扫的那个位再进，方向对着被挤出去的那一边。
- **目标**：被挤出的那一段的起点，或上一个盘整区。挤仓走得快，别拿它当趋势起点。
- **失效**：收盘仍留在被扫的一侧，或第二波强平紧接着来——清算还没结束。

### 均值回归（区间市）

- **条件**：价格在明确高低区间震荡，ADX 偏低、均线纠缠，无清晰趋势。
- **入场**：触及布林上/下轨或区间边界，RSI 进入超买/超卖并出现拒绝 K。
- **目标**：中轨或区间对侧；勿把震荡策略用在刚突破后的趋势日。
- **切换**：一旦收盘有效突破区间 + 放量，立刻停用回归思路。

## 组合禁忌与优先级

| 做法                          | 评价                        | 更好的替代                                |
| ----------------------------- | --------------------------- | ----------------------------------------- |
| RSI + Stochastic + CCI 同时看 | 弱：三者都是动量，高度相关  | 留一个动量，再加趋势与成交量              |
| 只看 MACD 金叉就开仓          | 弱：滞后，震荡市反复假信号  | 金叉 + 价格在关键均线一侧 + 结构位        |
| 布林上下轨当绝对买卖点        | 弱：趋势市会沿上轨/下轨奔跑 | 先判断趋势/震荡，再决定碰轨是反转还是顺势 |
| 指标参数天天调优              | 弱：过拟合近期行情          | 固定一小套参数，用多周期与结构过滤        |
| 小周期指标对抗大周期趋势      | 弱：胜率与盈亏比通常双差    | 大周期定方向，小周期只找入场              |

### 推荐「够用」的最小指标组

- 主图：EMA20 + EMA50（或 VWAP）+ 成交量
- 副图：MACD 或 RSI 二选一
- 波动：ATR 用于止损
- 临时：需要时加布林带看压缩/扩张
- 合约：可叠加持仓量与资金费率作过滤器

## 市场状态：先选策略，再选指标

同一套指标在不同状态下胜率差很多。开盘先看「现在是什么局」，再决定用顺势、突破还是回归。

| 状态      | 怎么认                                                | 适合                                             | 别用                                       |
| --------- | ----------------------------------------------------- | ------------------------------------------------ | ------------------------------------------ |
| 趋势      | 高低点抬高/降低，价格沿均线一侧走，ADX 偏高或带宽扩张 | 顺势回踩、突破接力、移动止损                     | 摸顶抄底、均值回归                         |
| 震荡      | 区间清晰、均线纠缠、假突破多                          | 区间边界反转、小仓快进快出                       | 追突破、宽止损扛单                         |
| 无序/chop | 上下影线长、方向反复、量能无配合                      | 空仓或极小仓试探                                 | 任何需要「干净趋势」的系统                 |
| 拥挤趋势  | 价格确实在走趋势，但资金费率单边极端、持仓量同步堆高  | 顺势但缩短持仓、提前落袋；或者等挤仓那一下再反手 | 在费率最高的时候加仓——那是接最后一棒的位置 |
| 极端波动  | ATR 暴增、强平潮、点差拉宽、插针                      | 减仓、只管理已有仓、等波动回落                   | 新开大仓、改止损到更远                     |

## 合约专属：价格、保证金、强平、资金费

这一节是合约和现货真正不一样的地方。上面所有关于结构和指标的内容，换个市场也成立；下面这些只在这里成立，而且它们不是知识点——它们是你的计划被交易所提前终止的几种具体方式。

### 标记价与触发价

- 强平永远按标记价算，标记价跟的是指数而不是这个盘口的最新成交价。所以一根针在图上刺穿了你的强平价，你却还活着——图画的是最新价。
- 止损用哪个价触发是你自己选的：标记价，薄盘口的一根针扫不掉你；最新价，你会实打实被那根针成交出去。默认值各家不同，开仓前确认一次，这是合约上最容易被白白扫损的一个设置。
- 代价是标记价略滞后，真突破时晚一点点确认。用标记价触发、把止损放在结构外，比用最新价触发再把止损放得更远划算。

### 保证金与强平

- 逐仓：单笔最大损失封顶在本仓保证金，适合试错与方向不确定的单。全仓：账户共享保证金，抗波动强，但一笔失控可拖垮整户。
- 逐仓强平价粗算：距入场约 (1÷杠杆 − 维持保证金率)。10× 配 0.5% 的维持保证金是约 9.5%，不是 10%——差的那一截正好在你最需要它的地方。
- 强平必须远在结构失效位之外。它要是落在止损附近，这笔交易怎么结束就不由你的计划决定了。

### 资金费

- 费率是持仓成本，不是方向信号。极端正/负费率说明一侧拥挤，而拥挤可以持续很久。
- 费率按名义价值收，不按保证金——它跟着仓位走，不跟着你的风险走。止损 1% 的仓位，0.05% 的费率每次结算吃掉 5% 的 R，一天三次就是 15%。
- 多数合约 8 小时结一次，也有 4 小时和 1 小时的。跨结算就把它算进盈亏比；费率 + 基差 + 多空比同向极端，那是挤仓的 setup，不是追单的理由。

| 还会咬你的   | 是什么                                                                                         | 怎么办                                                                         |
| ------------ | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 阶梯保证金   | 仓位越大，维持保证金率越高、可用杠杆越低。强平比按 1÷杠杆 算出来的更近                         | 仓位上一个台阶就重算一次强平价，别沿用小仓时的直觉                             |
| ADL 自动减仓 | 极端行情下保险基金不够赔时，交易所强行减掉盈利方的仓位，按盈利和杠杆排队                       | 赚得多、杠杆又高的时候你排在最前面。大行情里主动分批落袋，好过被系统替你选时点 |
| 持仓模式     | 单向模式下，一笔超过持仓量的反向单会把你反手开到另一边；双向模式可同时持多空，但两边都付资金费 | 默认单向。双向大多数时候是拖延认错的工具，不是对冲                             |
| reduce-only  | 只减不增的标志。没有它，一个写大了的平仓单会把你从多头直接翻成空头                             | 所有止损止盈都挂上，这是一次性设置的事，不该每笔去想                           |

## 杠杆经验区间与品种选择

杠杆不决定风险——风险是止损距离 × 仓位 ÷ 权益，前面已经说过。杠杆决定的是另一件事：强平价离入场有多近。所以选杠杆只有一个标准，强平必须远在结构失效位之外，中间还要留得下一根插针。下表是逐仓下的粗略距离（约 1÷杠杆），未计维持保证金与已实现盈亏，实盘会比这更近一些。

| 杠杆档 | 强平大致离入场（逐仓） | 这意味着什么                                                                                                     |
| ------ | ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 2–5×   | 约 20%–50%             | 几乎不可能先于止损被强平，止损宽度可以完全按结构定。多数单子待在这里不是因为它「安全」，而是因为它让强平退出决策 |
| 5–10×  | 约 10%–20%             | 仍远在多数结构失效位之外；适合失效位本来就近、流动性好的短线                                                     |
| 10–20× | 约 5%–10%              | 开始和常见止损宽度同量级。一次插针可能先碰强平再碰止损——那笔就不是按 R 结束的                                    |
| 20×+   | 低于 5%                | 强平落在噪音范围内，止损失去意义：先被平掉的是仓位，不是计划                                                     |

| 品种档          | 怎么选                                                        | 仓位建议                                     |
| --------------- | ------------------------------------------------------------- | -------------------------------------------- |
| 主流（BTC/ETH） | 点差窄、深度好、行为相对可复现                                | 可作为默认交易对象；相关仓合并计风险         |
| 一线山寨        | 跟 BTC 同向但振幅更大（beta 更高：BTC 动 1%，它常动 1.5%–3%） | 仓位小于 BTC；突破假动作更多，确认门槛提高   |
| 低流动性小币    | 易被扫、易插针、易被人控盘                                    | 默认不做；非做不可则逐仓 + 极小 R + 不扛过夜 |

## 执行、出场与加仓

| 主题        | 要点                                                                                                                                                                               |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 止损单类型  | 剧烈波动用止损市价（保证出场）；流动性好时可止损限价，但要接受未成交风险。                                                                                                         |
| 滑点预期    | 插针、强平潮、重大数据窗口，实际成交价可能比图表差一截；仓位要为此留余量。                                                                                                         |
| 分批止盈    | 第一目标平 30%–50%，止损上移到保本或结构位、取更靠外的那个——保本价通常比失效位近得多，无条件挪过去等于主动把余仓送给噪音扫。余仓用结构或 trailing 跟趋势，别全仓等一个「完美顶」。 |
| 加仓        | 只在盈利后、且新仓有独立失效位时金字塔加码；亏损单禁止摊平——摊平是换大风险赌方向。                                                                                                 |
| reduce-only | 止损与止盈一律挂 reduce-only。单向模式下，一个写大了的平仓单会把你直接反手开到另一边——那不是止损，那是一笔没有计划的新仓。                                                         |
| 交易成本    | 手续费是每笔都付的固定税，页面其他地方算了资金费和滑点，唯独别忘了它：来回吃单约 0.1%，止损宽 0.8% 时就吃掉超过 12% 的 R。止损越紧、频率越高，它越致命。                           |
| 最低盈亏比  | 入场前粗算：若止损 1R，目标至少 1.5R–2R，否则胜率要极高才值得做。R 按净的算——先扣手续费、资金费与预期滑点。                                                                        |
| 期望值      | 胜率 × 平均盈利 − 败率 × 平均亏损 > 0 才长期可活，而且要用扣完成本的净值算，毛的那个数长期是假的；只记盈亏不记 R 倍数，看不出系统在不在退化。                                      |

## 时间与事件

| 窗口                    | 注意什么                                                                                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 资金费结算前后          | 波动常放大，费率极端时小心被动平仓与假突破；无明确 edge 可避开结算前后 15–30 分钟。                                                                |
| 宏观数据（CPI/FOMC 等） | 点差与滑点恶化，结构失效位容易被扫；事件前减仓或只做已有仓管理。                                                                                   |
| 周末 / 节假日           | 流动性变薄，假突破与插针增多；仓位减半或提高入场门槛。                                                                                             |
| 交易时段                | 亚洲盘常在区间里磨，欧洲盘开方向，美盘给出当日最大波动与最多假动作。同一套配方在不同时段胜率不一样——复盘时按时段分开统计，比按品种分更能看出问题。 |
| 上新 / 维护 / 链上异常  | 交易所公告、充提暂停、合约下架——不确定时不开新仓。                                                                                                 |

## 常见翻车场景

| 场景               | 为什么亏                                             | 拦截办法                                                         |
| ------------------ | ---------------------------------------------------- | ---------------------------------------------------------------- |
| 止损拉到失效位外   | 「再给一点空间」= 单笔风险失控                       | 先定 R，再定止损；止损动一次就要重算张数                         |
| 大赢后立刻加码     | 兴奋状态下放大仓位，一次回吐吃掉一周                 | 大赢后下一笔恢复标准仓；当日不再提高单笔风险                     |
| 连亏后换品种追     | 报复式切换，没有 edge 只是换地方赌                   | 连亏先停下复盘再决定做不做；换品种不算「休息」                   |
| 看对方向扛回止损   | 方向对但仓位/杠杆错，仍会被扫出局                    | 方向与仓位是两件事；杠杆服务于失效位，不是服务于信心             |
| 把浮盈当已实现     | 未平仓利润加大仓，回撤时心态崩                       | 只有平仓才算赢；浮盈不加到「可用资金」里做下一笔                 |
| 被强平而不是被止损 | 杠杆太高，或触发价选了最新价，交易所先于你的计划出手 | 强平价必须远在失效位之外；止损用标记价触发，别让一根针替你做决定 |
| 强平潮里追方向     | 强平推动的 move 结束很快，接最后一棒                 | 强平可短打，不把 cascade 当新趋势起点                            |

## 与 Vigil 面板联动（可选规则）

面板不是下单信号机，是「噪音过滤器」。把它写进纪律，比凭感觉点卡片更稳。

| 规则                   | 怎么用                                                                   |
| ---------------------- | ------------------------------------------------------------------------ |
| 双家族亮圈才允许开新仓 | 价格家族 + 资金/持仓家族同时异常，才进入「可计划」名单；单条 3σ 只观察。 |
| 亮圈 ≠ 立刻市价追      | 亮圈后仍要等结构位与失效位；用小周期找回踩/确认，而不是追最后一根。      |
| compression 单独出现   | 只记「盘整中」，不计入开仓理由；等打破盘整时的那次行情再评估。           |
| 强平 / 极端费率        | 作过滤器或反向线索，不当趋势确认；极端费率下降低仓或缩短持仓。           |
| 自选数量               | strength 要求自选 ≥8 个才计算；板子太窄时相对强弱失真，别据此加仓。      |

逐条读数该当什么用。左边是 signals.zh.md 里的名字，右边是它在一笔交易里的位置。这一张说的是「圈亮了之后该做什么」；读数本身怎么解读，尤其合约那几条，在上面「合约数据」一节。大多数读数是过滤器或时机，只有很少几条能当方向。

| 读数                    | 当什么用                                           | 别当什么用                                     |
| ----------------------- | -------------------------------------------------- | ---------------------------------------------- |
| momentum                | 异动提醒：这个品种刚才动了，值得调图看结构         | 别当入场信号——5 分钟的偏离说不出方向能延续多久 |
| volatility              | 止损宽度的输入：振幅变大就该把仓位调小             | 别当趋势确认，它只报扩张不报方向               |
| compression             | 盯盘名单：波动压缩后常有一段趋势，提前把关键位画好 | 别当开仓理由，压缩可以持续很久                 |
| breakout / range-break  | 结构证据：配合放量时是「突破接力」配方的触发       | 无量时别追，先按假突破处理                     |
| rejection               | 失效位的证据：长影拒绝的那一端可以当止损参考       | 单根 K 不构成反转，等结构确认                  |
| strength                | 选品种：同样看多时挑扣掉大盘后仍强的那个           | 板子少于 8 个自选时不要用                      |
| volume                  | 确认层：突破、反转都要它签字                       | 放量本身没有方向，别单独用                     |
| taker                   | 方向证据里比较硬的一条：谁在越过价差促成成交       | 极端读数常出现在行情末端，别在冲高时追         |
| open-interest           | 判断是新钱还是平仓：价涨 + 持仓增才像新趋势        | 价涨 + 持仓降是平空推动，别当趋势起点          |
| liquidation             | 风险开关：强平潮里降杠杆、拉宽预期滑点             | 绝不当趋势确认，cascade 结束得很快             |
| ratio / divergence      | 拥挤度：一侧过度拥挤时提高确认门槛或反向找机会     | 拥挤能持续数周，不能当择时                     |
| funding / funding-shift | 持仓成本与拥挤度：跨结算前算进盈亏比               | 不是方向信号                                   |
| basis                   | 现货与合约的分歧：极端时警惕合约端单边情绪         | 基差回归的时间不确定，别据此重仓               |
| spread                  | 交易成本的红灯：价差变宽说明这时候进出都要付更多   | 价差宽的时候不该是你开新仓的时候               |

## 交易纪律

### 仓位与风险

- 风险 = 止损距离 × 仓位 ÷ 权益；不是杠杆，也不是保证金用了多少。
- 基准 1%，上沿 2%，按下面的档位表选。决定它的是你有没有验证过的样本，不是你想赚多少；也别拿「1% 仓位太小」当提高风险的借口——1% 风险配 2% 止损就是 0.5 倍权益的名义仓位。
- 止损宽度用结构位或 1.5–2×ATR（默认 14 周期，取执行级别的那一根，不是结构级别），再反推张数；先定「想开多大」再硬塞止损，是爆仓的常见路径。
- 当日亏到 4R–6R → 收工。这条是硬的，因为它直接约束钱；用 R 而不是固定百分比，是为了换档位时它跟着走。
- 连亏 3 笔 → 停下来复盘，但不必然收工：45% 胜率下大约每六组三笔就会撞上一次，它多半在说市场状态变了或执行走样，而不是系统坏了。
- 同向相关仓（BTC+ETH）合并计风险。

### 入场与出场

- 先写计划：市场状态（趋势/震荡）、触发、失效位、目标、仓位。
- 止损是入场的一部分；没有失效位 = 没有交易。
- 盈利后移动保护止损；勿因「指标还没死」无限推迟离场。

### 行为约束

- 禁止：报复单、摊平亏损、无计划的「感觉要涨」。
- 禁止：重大数据/上币/维护窗口开满仓。
- 允许空仓。没结构、没多源确认时，看盘 ≠ 必须交易。

选哪一档不是偏好问题，是拿回撤换单笔收益的绝对值。按 45% 胜率估，250 笔里最长的一段连亏约 9 笔（ln(250) ÷ ln(1÷0.55)）：光这一段，1% 档就是 8.6% 的回撤，2% 档 16.6%，3% 档 24.0%。把前后穿插的零星亏损也算进去，正常年份的峰谷回撤大致就是下表右列。

| 单笔风险 | 什么时候用这一档                                                                                                | 正常年份的峰谷回撤 |
| -------- | --------------------------------------------------------------------------------------------------------------- | ------------------ |
| 0.5%     | 校准期：按 R 记录的样本还不到 50 笔，或期望值尚未转正。没验证过的系统，把风险开大只是把没有 edge 这件事做得更快 | 7%–9%              |
| 1%       | 默认档。系统已验证，交易频率不低                                                                                | 13%–17%            |
| 2%       | 上沿。已验证且低频（一周几笔，不是一天几笔），并且你现在就接受右列这个数                                        | 25%–33%            |
| 3%       | 不是一档，是例外。每次都要写下这次为什么值得，写不出来就是没有理由                                              | 36%–48%            |

这是量级不是保证，而且它假设每次都恰好亏 1R——合约上插针与滑点会让实际亏损常在 1.2R 附近，右列还要再往上乘一点。用法只有一条：选 2% 就等于现在就接受 25%–30% 的回撤。接受不了，现在把数字调小；等回撤发生时再改规则，那不是风控。

## 开仓前检查表

- [ ] **市场状态**：现在是趋势还是震荡？用的策略是否匹配？
- [ ] **大周期方向**：日线/4H 是否支持这笔方向？
- [ ] **结构与失效位**：关键位在哪？破哪一价你认错？
- [ ] **多源确认**：趋势/动量/量能是否至少两类同向？
- [ ] **仓位公式**：风险金额 ÷ 止损距离（可用 ATR）是否算过？
- [ ] **强平价**：逐仓/全仓下，强平是否远在失效位之外？（约 1÷杠杆 − 维持保证金率）
- [ ] **触发与模式**：止损挂了吗？触发价是标记价还是最新价？reduce-only 开了吗？
- [ ] **持仓时长**：若跨资金费结算，费率成本是否仍值得做？
- [ ] **事件窗口**：接下来 1 小时有无数据/维护/极端波动？
- [ ] **面板确认**：若用 Vigil：是否跨两个信号家族？还是单条噪音？
- [ ] **情绪状态**：刚亏完、熬夜、大赢后兴奋、急于回本？是则跳过。

### 仓位计算

先定风险，再由止损距离反推张数——顺序反过来就是爆仓的那条路。

```
风险金额 = 权益 × 风险%；仓位 = 风险金额 ÷ |入场价 − 止损价|；名义价值 = 仓位 × 入场价；所需杠杆 = 名义价值 ÷ 权益。
```

所需杠杆是这笔仓位需要的最低杠杆，不是建议值——它越高，说明止损相对越近、越经不起插针。手续费与资金费不在其中。

| 维度         | 记录什么                                                 |

| 情绪笔记     | 恐惧/贪婪出现在哪一步？下次如何拦截？                    |

## 一句话纪律

> 结构定方向，指标做多源确认；只交易有失效位的计划单。

无计划不下单 · 无止损不开仓 · 不堆同类指标 · 不摊平 · 不报复 · 先认状态 · 空仓也是仓位
